        Safety rules

        Hermes is the brain now, so these rules are enforced by Hermes and its tools, not set here. To change them, change Hermes.

        • Always asks you, every time: sending an email, sending invitations, changing or cancelling an event other people are on, opening a program you downloaded. No “always allow”; no answer means no.
        • Does on its own, in a chat that has only heard from you: reading your email and calendar, saving drafts, adding or changing your own events, opening apps, websites and files, notifications, reading the screen or clipboard.
        • Commands and files on this PC: risky commands are flagged; Hermes’s smart check allows the low-risk ones and asks you about the rest. Scheduled and unattended jobs are refused instead of asking.
        • Memory: Hermes asks before saving anything to its memory.
        • Once a chat has read text someone else wrote (an email, an event, a web page, the screen, the clipboard, a download): everything except plain reading asks first, until you start a new chat. If that chat has also read your own files or mail, web searches ask too.
        • Jarvis’s and Hermes’s own files (settings, safety rules, code): changing them always asks.
